# Aniket Deb — Responsive Portfolio

A responsive personal portfolio built with plain HTML, CSS and JavaScript.

## Included
- Responsive layout for Android, iPhone, iPad/tablet and desktop screens
- Professional profile photo supplied for this portfolio
- CV PDF with browser preview and download button
- Mobile navigation menu
- Scroll progress indicator and back-to-top button
- Reveal-on-scroll animations with reduced-motion support
- Aviation-inspired navy / blue visual system

## Run
Open `index.html` in a browser. Keep the folder structure unchanged so the photo and CV paths continue to work.
